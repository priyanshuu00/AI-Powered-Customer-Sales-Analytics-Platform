# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Production Release
### Added
- **Phase 1**: Environment setup, `requirements.txt`, and virtual environment configuration.
- **Phase 2**: MySQL relational schema (`schema.sql`) and relationships defined for the Olist dataset.
- **Phase 3**: Robust Python ETL pipeline featuring comprehensive data validation and SQLAlchemy bulk insertion.
- **Phase 4**: SQL Analytics Engine with advanced CTE queries, Indexing optimization, and analytical Views.
- **Phase 5**: Python EDA module utilizing Pandas, Matplotlib, and Plotly to generate static reporting charts.
- **Phase 6**: Apache Spark distributed processing pipeline demonstrating enterprise scalability (Caching, Repartitioning, Broadcast Joins).
- **Phase 7**: Interactive Streamlit Web Dashboard visualizing all core KPIs.
- **Phase 8**: Gemini-powered AI Business Intelligence Engine for automated Insight and Recommendation generation.
- **Phase 9**: Comprehensive project documentation, test suite initialization, and GitHub deployment preparation.
