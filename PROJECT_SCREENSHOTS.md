# Project Screenshots Checklist

To ensure your GitHub repository looks professional and engaging, capture and upload the following screenshots to a `/docs/images/` folder and embed them in your `README.md`.

## 1. Streamlit Dashboard (Executive Overview)
- **Capture:** The main landing page showing the dark-themed KPI cards (Total Revenue, Orders, Customers, Avg Rating).
- **Purpose:** Hooks the viewer immediately with a polished UI.

## 2. Interactive Charts (Sales & Customers)
- **Capture:** The Plotly Line charts (Monthly Revenue) and Bar charts (Top Categories) with a filter actively applied in the sidebar.
- **Purpose:** Demonstrates front-end interactivity and data visualization skills.

## 3. Terminal Output: Spark Processing
- **Capture:** The console output showing the Spark execution time, partition counts, and optimization logs.
- **Purpose:** Proves big-data capability and distributed systems knowledge to Data Engineering recruiters.

## 4. AI Generated Report
- **Capture:** A snippet of the `ai_business_report.md` showing the Gemini-generated Root Cause Analysis and Recommendations.
- **Purpose:** Highlights cutting-edge Generative AI integration.

## 5. MySQL Database ERD
- **Capture:** The schema diagram from MySQL Workbench.
- **Purpose:** Demonstrates foundational relational database design skills (3NF).
